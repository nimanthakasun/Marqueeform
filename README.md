# Marquee form sample
You will neded Restsharp to run this. If it's not in your system, do the following
 - Go to the Solution View of the solution from the "Solution explorer".
 - Right click on "Dependancies".
 - Go to "Manage Nuget packages".
 - Go to "Browse" tab.
 - Search for "RestSharp".
 - Click on it and click install (I was using version 112.1.0 when I was creating this project. I think that's the latest version).
